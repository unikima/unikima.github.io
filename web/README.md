# رابط کاربری وب — Next.js + TypeScript

این پوشه، لایه‌ی نمایش سامانه‌ی توصیه‌گر کتاب است.

## اجرا

```bash
npm install      # فقط بار اول
npm run dev      # اجرا در حالت توسعه
```

سپس نشانی `http://localhost:3000` را در مرورگر باز کنید.

برای ساخت نسخه‌ی نهایی:

```bash
npm run build
npm start
```

## معماری

نکته‌ی اصلی طراحی این است که **هیچ سرور پشتیبانی وجود ندارد**. پس از آموزش
مدل‌ها در پایتون، آنچه برای تولید پیشنهاد لازم است چند ماتریس عددی بیش نیست.
اسکریپت `src/export_web.py` در پروژه‌ی پایتون آن ماتریس‌ها را به فایل‌های
دودویی فشرده تبدیل و در `public/model/` قرار می‌دهد، و موتور توصیه‌گر
(`src/lib/model.ts`) آن‌ها را در مرورگر می‌خواند و محاسبه را همان‌جا انجام
می‌دهد.

پیامدهای این انتخاب:

- استقرار رایگان و ساده روی هر میزبان ایستا (مانند Vercel)
- پاسخ آنی، بدون رفت‌وبرگشت شبکه
- هیچ داده‌ای از کاربر جایی ارسال نمی‌شود
- مجموع حجم مدل‌ها حدود ۹ مگابایت است که یک‌بار بارگذاری و سپس در حافظه‌ی
  نهان مرورگر نگهداری می‌شود

## ساختار

```
src/
├── app/
│   ├── layout.tsx          چیدمان کلی، فونت و راست‌به‌چپ
│   ├── page.tsx            صفحه اصلی: پیشنهاد کتاب
│   ├── similar/page.tsx    کاوش کتاب‌های مشابه
│   ├── results/page.tsx    نتایج ارزیابی
│   └── about/page.tsx      درباره پروژه
├── components/
│   ├── Recommender.tsx     منطق صفحه اصلی
│   ├── SimilarExplorer.tsx کاوشگر شباهت
│   ├── Results.tsx         جدول و نمودارهای ارزیابی
│   ├── Charts.tsx          نمودارهای SVG، بدون کتابخانه بیرونی
│   ├── BookCard.tsx        کارت کتاب
│   ├── BookSearch.tsx      جستجوی کتاب
│   └── Nav.tsx             نوار پیمایش
├── lib/
│   ├── model.ts            موتور توصیه‌گر
│   ├── types.ts            تعریف نوع‌ها
│   └── format.ts           قالب‌بندی اعداد فارسی
└── fonts/                  فونت وزیرمتن (میزبانی محلی)
```

## به‌روزرسانی مدل‌ها

اگر مدل‌ها را دوباره آموزش دادید، برای انتقال نتایج به این برنامه:

```bash
cd ..                       # به ریشه پروژه
python -m src.train         # آموزش مجدد (اختیاری)
python -m src.export_web    # استخراج به public/model/
```

## استقرار روی Vercel

۱. پوشه‌ی پروژه را روی GitHub بگذارید.
۲. در `vercel.com` وارد شوید و مخزن را وارد کنید.
۳. در تنظیمات، مقدار Root Directory را روی `web` بگذارید.
۴. دکمه Deploy را بزنید.

نیازی به تنظیم متغیر محیطی یا پایگاه داده نیست.
